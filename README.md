# asa

## [neon-cascade/](neon-cascade/)

A Magic Tiles-style rhythm game built as a single self-contained
`index.html` — no build step, no dependencies, no external assets.
Targets iPad Mini (Safari / Chrome), portrait, touch only.

```
open neon-cascade/index.html
```

### Playing it on a tablet

The file is fully self-contained, so any static host works. To serve it from
this repo, enable **Settings → Pages**, pick this branch as the source, and the
game is live at `https://<user>.github.io/asa/neon-cascade/` — add that to the
home screen for a chrome-free, full-screen launch.

See [neon-cascade/README.md](neon-cascade/README.md) for the design notes
and tuning surface.
