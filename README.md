# asa

## [neon-cascade/](neon-cascade/)

A Magic Tiles-style rhythm game built as a single self-contained
`index.html` — no build step, no dependencies, no external assets.
Targets iPad Mini (Safari / Chrome), portrait, touch only.

```
open neon-cascade/index.html
```

See [neon-cascade/README.md](neon-cascade/README.md) for the design notes
and tuning surface.
